# Long-Term Roadmap & Strategy — Rabnix Estate

> **Version:** 1.0.0 · **Status:** Draft · **Last updated:** 2026-08-16 · **Owner:** Product

## 1. Strategic sequencing (the meta-plan)
The single most important long-term decision: **sequence supply → liquidity → demand →
monetization → moat.** Skipping ahead kills marketplaces.

```
Phase 0 (pre-launch)   Seed supply in ONE dense locality. Manual + agent partnerships.
Phase 1 (0–3 mo)       MVP live, hyper-local. Goal: liquidity in a few localities.
Phase 2 (3–9 mo)       Trust + retention (alerts, verification, SEO). Goal: organic demand engine.
Phase 3 (9–18 mo)      Monetize supply (agent plans, featured). Goal: revenue without hurting trust.
Phase 4 (18–36 mo)     Data moat (price/locality insights) + multi-city + partnership revenue.
```

## 2. Roadmap themes (not just features)

| Horizon | Theme | Why now |
|---------|-------|---------|
| **Now** | Transactable + trustworthy core | Nothing matters until the loop works and inventory is real |
| **Next** | Retention & organic acquisition | Alerts + SEO reduce CAC; marketplace compounds only if buyers return |
| **Later** | Monetize without degrading trust | Ads/featured must be clearly labeled or you become the spam you replaced |
| **Bet** | Data & insights moat | Proprietary enquiry/transaction data → price trends nobody else has → defensibility |

## 3. Monetization strategy (sequenced — never charge before delivering value)
1. **Free listings** to build inventory (loss leader).
2. **Featured / boosted listings** — first revenue, aligns with lister intent.
3. **Agent subscriptions** — tiered by listing count + lead volume + analytics.
4. **Verified badge as paid tier** for agents (trust-as-a-service).
5. **Referral revenue** — home loans, legal/title check, movers, insurance.
6. **Data products (later)** — locality reports, valuation API for banks/developers.

**Guardrail:** the demand side (buyers) stays **free forever** — it's the scarce, courted side.

## 4. Defensibility — why you won't be copied to death
Features are copyable; these compound and aren't:
- **Verified-inventory reputation** — years of consistent moderation to earn.
- **SEO authority** — domain + content authority is a moat that grows daily.
- **Proprietary enquiry/transaction data** — powers insights competitors can't match.
- **Local liquidity density** — being *the* place for a locality locks in both sides.

## 5. Team & operating model
Marketplaces are ops-heavy, not just eng-heavy:
- **Eng:** small full-stack team (2–4) can run through Phase 2.
- **Ops/Moderation:** hire early — trust is manual before it's automated.
- **Supply/Sales:** feet-on-street or tele-sales to seed & grow agent inventory — often the real
  growth engine, not marketing.
- **Cadence:** weekly review vs. North Star (qualified enquiries/wk) + guardrail (response rate).

## 6. What we deliberately will NOT do
- No microservices before scale forces it.
- No multi-city until one city hits liquidity — spreading thin is the #1 marketplace death.
- No home-loans/interiors/CRM in v1 — resist the super-app temptation until the core compounds.
- No paid demand marketing before supply liquidity — don't pump buyers into an empty store.

## 7. Milestone definition of done

| Phase | Exit criteria |
|-------|---------------|
| 0 → 1 | ≥ N verified live listings in the seed locality; posting flow < 3 min |
| 1 → 2 | Time-to-first-enquiry < X days; repeat searches happening organically |
| 2 → 3 | Meaningful organic/SEO demand; enquiry response rate above guardrail |
| 3 → 4 | Paying agents at healthy retention; revenue not degrading trust metrics |

*(N and X to be set once target city & seeding channel are chosen — see PRD §7 open questions.)*
